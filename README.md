# RN Web Starter (Expo + react-native-web + TypeScript)

This is a minimal starter scaffold for a single codebase that runs on Web + iOS + Android using Expo + react-native-web.

Quick start:
1. Install dependencies:
   npm install

2. Run on web:
   npm run web
   (or `npx expo start --web`)

3. Build production web bundle:
   npm run build:web
   The output will be in `web-build/` (or `dist/`) depending on your Expo version.

Notes:
- This scaffold uses TypeScript. If you prefer JavaScript, rename `.tsx` -> `.js` and adjust tsconfig-related files.
- If you want server-side rendering / SEO, consider a Next.js + react-native-web setup instead.
